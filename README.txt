ATMOS — Weather API Website

Built with HTML, CSS and vanilla JavaScript only.

HOW TO RUN
1. Extract ZIP.
2. Open index.html in a browser.
3. Search any city. Internet connection required.

API: Open-Meteo Geocoding + Forecast (free, no API key).
Features: current weather, 7-day forecast, city search, saved last city, responsive design.

DEPLOY TO VERCEL
Upload the extracted folder to a static Vercel project. No build command is required.

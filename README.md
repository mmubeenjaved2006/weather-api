## 📖 About the Project

ATMOS is a modern weather dashboard that allows users to search for cities and view real-time weather information and forecasts.

The application uses the Open-Meteo API to retrieve weather data and provides a responsive interface for desktop, tablet, and mobile devices.

## ✨ Key Features

- 🌡️ Current weather conditions
- 📅 7-day weather forecast
- 🔎 City-based weather search
- 📍 City lookup using Open-Meteo Geocoding API
- 💾 Saves the last searched city
- 📱 Fully responsive design
- ⚡ Fast and lightweight interface
- 🔑 No API key required

## 💻 Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/mmubeenjaved2006/weather-api.git
```

**2. Navigate to the project directory**

```bash
cd weather-api
```

**3. Run the application**

Open `index.html` in your browser.

No additional dependencies or API keys are required.

## 🌐 API Integration

ATMOS uses two Open-Meteo services:

**Geocoding API**

Converts a city name into geographical coordinates.

**Forecast API**

Retrieves weather conditions and forecast information using the selected location.

Official documentation: https://open-meteo.com/
